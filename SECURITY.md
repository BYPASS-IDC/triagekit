# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.9.x   | Yes       |

## Reporting a vulnerability

If you discover a security issue in TriageKit itself (the tool, not a scan target):

1. **Do not** open a public GitHub issue with exploit details.
2. Email or use the private disclosure channel listed in the repository (or create a private security advisory on GitHub).
3. Include steps to reproduce, impact, and any suggested fix if you have one.

We aim to acknowledge reports within a few days and to ship fixes for confirmed issues as quickly as practical.

## Authorized use

TriageKit is a defensive scanner. You must only point it at systems and repositories you own or have explicit written permission to test. See `skills/01-authorized-use.md` for the policy gate the tool itself enforces.

Unauthorized scanning is not permitted by this project or its license.
